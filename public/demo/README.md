# Demo Images

Place your pre-generated AI images here for demo mode.

## File naming convention:

- `clean-1.jpg` - Clean/professional style result
- `festive-1.jpg` - Festive style result
- `artistic-1.jpg` - Artistic style result
- `rustic-1.jpg` - Rustic style result
- `upscaled-1.jpg` - Upscaled image result
- `no-bg-1.jpg` - Background removed result

You can add multiple versions (clean-2.jpg, clean-3.jpg, etc.) and the API will randomly pick one.
